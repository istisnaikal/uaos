# Name check: `uaos`

**Date:** 2026-10-13 · **Scope:** the engineering name `uaos` (crates, binary, repository). The
product brand is a separate, final work package and needs its own check.

| Where | Finding | Source |
|---|---|---|
| crates.io | `uaos`, `uaos-contracts` and `uaos-runtime` are unclaimed | `crates.io/api/v1/crates/<name>` |
| GitHub | 34 repositories match "uaos" by name. The most visible is an unrelated bare-metal hobby OS, `stevereaver/uaos` (13 stars); the rest are small or empty | GitHub repository search |
| Trademarks, web search only | No registered "UAOS" mark found. A similar US word mark exists: **"UOS"** (Uniontech Software Technology), serial 88854310, covering operating-system software | web search; [USPTO record via Justia](https://trademarks.justia.com/owners/uniontech-software-technology-co-ltd-4359124) |

**What this is not.** A web search is not a clearance search. TURKPATENT, EUIPO (TMview), USPTO
and the WIPO Global Brand Database must be searched for "UAOS" and close variants in classes 9
and 42 as part of the legal review (plan P8), and before any brand is registered.

**Consequences now.**
- The crate names can be reserved when the first crate is published. Publishing is an external
  action and waits for the maintainer's decision.
- The hobby-OS repository and the "UOS" mark are a reason to keep "UAOS" as the engineering
  name and to choose the product brand separately, as already planned.
